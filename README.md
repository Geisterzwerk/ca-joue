# Ça joue 🇨🇭

Persönliche Web-App zum Französischlernen für die Romandie: Chat-Missionen, Mithören, Aussprache und ein Satz des Tages, mit Claude als Gesprächspartner.

- `npm install` und `npm run dev` startet die App lokal
- Bei jedem Push auf `main` baut GitHub Actions die App und stellt sie auf GitHub Pages
- Der Claude-API-Schlüssel wird nur im Browser (localStorage) gespeichert
